# MY.

**MY.** est une webapp de gestion de collections de cartes Pokémon TCG.

Le projet s'appuiera sur **TCGdex / cards-database** comme source de référence pour les données Pokémon TCG.

Ce dépôt regroupera la documentation, le code source, les données, les configurations, les outils et les fichiers nécessaires au développement et à la maintenance du projet. Sa documentation sert de référence aux agents et contributeurs participant à sa conception et à son développement.
